# SPD 2026 — Sistemas Paralelos e Distribuídos

Repositório com os exercícios, projetos e anotações desenvolvidos durante a disciplina de **Sistemas Paralelos e Distribuídos**.

## Sobre

Este repositório reúne os exercícios práticos feitos em Java ao longo do curso, com foco em:

- Threads e `Runnable`
- Condições de corrida (*race conditions*) e seções críticas
- Sincronização (`synchronized`, locks)
- `ExecutorService` e pools de threads
- Simulações e experimentos de concorrência

## Estrutura

Cada exercício/projeto fica em sua própria pasta, geralmente organizada como um projeto NetBeans (Ant ou Maven).

```
SPD-2026/
├── projaula4/     # Simulação de corrida com pódio compartilhado (threads, sincronização)
└── ...
```

## Tecnologias

- Java (JDK 17+)
- NetBeans IDE
- `java.util.concurrent` (ExecutorService, ThreadLocalRandom, etc.)
